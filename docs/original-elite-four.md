# Original Elite Four and Champion

Design notes for a later Crownspire league. Isolde, Brannock, Morwenna, Tobiah, and Rosalind are portrait ids only in this change.

The portraits are registered in `portrait-manifest.js` and can be shown now. Nothing in this file changes gyms, teams, levels, or rewards.

## Original Elite Four and Champion — Crownspire Summit (Pokémon League)
Follows the 8 gyms (Rowan Grass, Lyra Electric, Flint Fire, Sera Water, Tamsin Ground, Orrin Psychic, Corwin Ghost, Kaelan Dragon; Kaelan tops at Lv 39).
All species are playable in the repo (species-data.js, kanto-species.js, habitat-species.js, additional-species.js).
