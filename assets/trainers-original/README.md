# Original trainer class portraits

Original Greenwood classes. They are available by id and are not assigned to a current NPC.

`trainer-portraits.js` loads each id on demand: WebP first, then PNG. These are not part of the classic atlas.

## Formats

Each ID has a 256×256 transparent `{id}.png` and a matching `{id}.webp`.
