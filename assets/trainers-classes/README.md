# Trainer class chibi portraits

Generic official trainer classes. Fern the Bug Catcher and Hugo the Hiker use the matching class portrait in the world. The other classes are available by id for later trainers.

`trainer-portraits.js` loads each id on demand: WebP first, then PNG. These are not part of the classic atlas.
