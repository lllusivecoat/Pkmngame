# Original Elite Four and Champion portraits

Portraits for a later Crownspire league. They are available by id and do not have battles yet. Designs and teams are in `docs/original-elite-four.md`.

`trainer-portraits.js` loads each id on demand: WebP first, then PNG. These are not part of the classic atlas.

## Characters

| ID | Name | Role |
| --- | --- | --- |
| `e4_isolde` | Isolde | Elite Four · Ice |
| `e4_brannock` | Brannock | Elite Four · Rock/Steel |
| `e4_morwenna` | Morwenna | Elite Four · Poison/Dark |
| `e4_tobiah` | Tobiah | Elite Four · Flying |
| `champ_rosalind` | Rosalind | Champion |

## Formats

Each ID has a 256×256 transparent `{id}.png` and a matching `{id}.webp`.
